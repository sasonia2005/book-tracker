# Book Tracker - Трекер прочитанных книг

## Описание
Консольное приложение для учета прочитанных книг с возможностью выставления оценок и просмотра статистики.

## Установка и запуск

### Требования
- Python 3.7+

### Установка
```
git clone https://github.com/sasonia2005/book-tracker.git
cd book-tracker
```

### Запуск
```
python main.py.txt
```
